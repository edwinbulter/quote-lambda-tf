# Quote Azure Backend - Source Code

This directory contains the complete source code for the Azure Functions backend implementation.

## Folder Structure

```
src/
├── Models/              # Data models and entities
│   ├── Quote.cs         # Quote entity model
│   └── UserActivity.cs  # User activity models (favorites, history, preferences)
├── Services/            # Business logic services
│   ├── IQuoteService.cs         # Quote service interface
│   ├── QuoteService.cs          # Quote service implementation
│   ├── IZenQuotesService.cs     # ZenQuotes API service interface
│   ├── ZenQuotesService.cs      # ZenQuotes API service implementation
│   ├── IUserActivityService.cs  # User activity service interface
│   └── UserActivityService.cs   # User activity service implementation
├── Data/                # Data access layer
│   ├── IQuoteRepository.cs      # Quote repository interface
│   ├── QuoteRepository.cs       # Quote repository implementation
│   ├── IUserActivityRepository.cs # User activity repository interface
│   └── UserActivityRepository.cs  # User activity repository implementation
├── Handlers/            # Azure Functions HTTP handlers
│   ├── QuoteHandler.cs          # Quote-related endpoints
│   └── UserActivityHandler.cs   # User activity endpoints
├── Program.cs           # Dependency injection and application configuration
├── host.json            # Azure Functions host configuration
├── local.settings.json  # Local development settings (not committed)
├── QuoteAzureBackend.csproj  # Project file
├── obj/                 # Build intermediates (generated during build)
├── bin/                 # Build output (generated during build)
└── publish/             # Published output (generated during deployment)
```

## Source Files

### Models
- **Quote.cs**: Core quote entity with properties like Id, QuoteText, Author, etc.
- **UserActivity.cs**: User-related entities including favorites, view history, and preferences

### Services
- **QuoteService**: Manages quote operations, random quote selection, and ZenQuotes integration
- **ZenQuotesService**: Handles external API calls to ZenQuotes service
- **UserActivityService**: Manages user favorites, view history, and preferences

### Data Layer
- **QuoteRepository**: Data access for quotes using Azure Table Storage
- **UserActivityRepository**: Data access for user activities using Azure Table Storage

### Handlers
- **QuoteHandler**: HTTP endpoints for quote operations (GET, POST, etc.)
- **UserActivityHandler**: HTTP endpoints for user activities (favorites, history, preferences)

## Build Output

### obj/ Directory
- Contains intermediate build files generated by MSBuild
- Automatically created during compilation
- Can be safely deleted (will be regenerated on next build)
- Not committed to version control

### bin/ Directory
- Contains compiled assemblies and executable output
- Automatically created during build
- Includes dependencies and runtime files
- Not committed to version control

### publish/ Directory
- Contains the packaged Azure Functions application
- Generated when running `dotnet publish` or deployment commands
- Ready for deployment to Azure
- Not committed to version control

## Development Workflow

1. **Local Development**: Use `local.settings.json` for local configuration
2. **Building**: Run `dotnet build` to compile the project
3. **Testing**: Use Azure Functions Core Tools for local testing
4. **Publishing**: Run `dotnet publish` to create deployment package
5. **Deployment**: Use the publish folder contents for Azure deployment

## Dependencies

- .NET 8 Runtime
- Azure Functions Core Tools
- Azure Storage SDK (for Table Storage)
- HttpClient (for ZenQuotes API integration)
- Microsoft.Extensions.DependencyInjection (for DI)

## Configuration

- **host.json**: Azure Functions runtime configuration
- **local.settings.json**: Local development settings (API keys, connection strings)
- **Program.cs**: Dependency injection setup and service registration
